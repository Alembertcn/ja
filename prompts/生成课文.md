# 提示词：生成练习短文（输出结构化 JSON）

用途：按 [N2学习计划](../docs/plan/N2学习计划_2027年7月.md) 的周次与模块号生成一篇短文，产物直接落到 `content/articles/<id>.json`，供 App 渲染。

使用方法：复制下面整段，把 `{...}` 换成实际值，发给 AI。

---

```text
请按仓库的课文数据契约生成一篇日语练习短文。

【契约】
严格遵守 content/schema/article.schema.json。只输出一个 JSON 对象，不要任何解释文字、不要 Markdown 代码围栏以外的内容。

【本次参数】
- 计划文件：docs/plan/N2学习计划_2027年7月.md
- id：{W24-zangyou}
- 周次 week：{24}    阶段 stage：{P2}    等级 level：{N2}
- type：article
- 必须覆盖语法模块 grammarModules：{G2-E01,G2-E02,G2-E05,G2-F05,G2-F08}
- 词汇主题 vocabTopic：{V2-T1}
- 文体：{だ・である（书面）}
- 篇幅：{500–700} 日文字，拆成 {20–30} 行

【逐行要求】
lines 数组按自然句切分，每句一个元素：
- id：l01、l02… 两位数顺序编号
- jp：日语原文，一行就是一个完整句子（含句号）
- reading：整句假名读音，保留原文的标点位置，不要插入空格
- romaji：罗马音，长音用 ō / ū 表示
- furigana：只给汉字部分标注。start / len 是该汉字串在 jp 中的字符下标与长度（从 0 开始数，标点也算一个字符），ruby 是对应假名。务必逐字核对下标，错位会导致 App 注音串行。
- zh：中文翻译，意译优先，保持中文通顺
- grammar：本行用到的语法点。module 必须来自计划里的模块号；point 写语法形式本身（如「～にもかかわらず」）；explain 用中文讲清接续、含义和易混点
- vocab：本行值得记的生词，word / reading / pos（名詞・動詞・い形容詞・な形容詞・副詞…）/ zh，必要时加 note
- isSentenceEnd：完整句结尾为 true

【内容要求】
- 目标语法每条至少自然出现一次，不要为了凑数硬塞
- 不要超纲堆砌 N1 生僻句型
- 词汇围绕指定主题，难度对齐指定等级
- title 用日语，titleZh 用中文，scene 一句话说明背景
- updatedAt 填今天的日期（YYYY-MM-DD）

【输出】
只输出 JSON 本体。生成后自检三项：
1) 每个 furigana 的 start/len 截出来的确实是对应汉字
2) grammarModules 里的每条都在 lines 的 grammar 里出现过
3) JSON 可被 json.loads 解析、字段名与 schema 完全一致
```

---

## 生成之后

```bash
python tools/build.py --check    # 校验 schema 与 furigana 下标
```

校验通过再提交。构建脚本会逐条核对 furigana 区间是否越界、是否真的落在汉字上，AI 数错下标能被当场拦下。
