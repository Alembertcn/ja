## JLPT 概要

| 项目 | 说明 |
|------|------|
| 全称 | 日本語能力試験（JLPT） |
| 级别 | N5（易）→ N4 → N3 → N2 → N1（难） |
| 是否必须逐级考 | **否**。可按水平直接报考任意一级 |
| 同一次考试 | **只能报一个级别**，不可同时报多级 |
| 考试频率 | 多数地区一年 **2 次**（约 7 月、12 月） |
| 2026 年日期 | **7 月 5 日**、**12 月 6 日**（周日） |

> 证书一般**无有效期**；个别学校、签证、单位可能要求「近 1～2 年成绩」，以对方要求为准。

---

## 一、整体流程

```text
了解考试 → 选级别 → 注册账号 → 报名选考点 → 缴费
    → 打印准考证 → 赴考 → 查成绩 → 领取证书/成绩单
```

| 阶段 | 做什么 | 大致时间（以中国大陆为例，每年略有调整） |
|------|--------|------------------------------------------|
| 1. 准备 | 选定级别、准备证件照片与身份信息 | 报名开始前 |
| 2. 注册 | 在报名网注册/完善个人信息 | 常比正式报名早几天开放 |
| 3. 报名缴费 | 选级别 + 考点并在时限内缴费 | 窗口通常约 1 周，热门考点易满 |
| 4. 准考证 | 登录系统用 A4 纸打印 | 一般考前约 1 周开放 |
| 5. 考试日 | 按准考证时间入场考试 | 7 月或 12 月某个周日 |
| 6. 查分 | 网上查成绩 | 考后约 **1.5～2 个月** |
| 7. 领证 | 到考点领取证书/成绩单 | 考后约 **3 个月**到考点；保存期约 **2 年** |

## 二、各节点：必要材料 + 网址

### 1）官方与报名入口（平时收藏）

| 用途 | 网址 |

| JLPT 官方（中文） | https://www.jlpt.jp/cn/ |
| 官方常见问题 FAQ | https://www.jlpt.jp/cn/faq/index.html |
| 官方样题 / 参考资料 | https://www.jlpt.jp/cn/samples/sampleindex.html |
| 资料下载（实施指南等） | https://www.jlpt.jp/cn/reference/materials.html |
| **中国大陆报名（教育网）** | https://jlpt.neea.edu.cn/ |
| **中国大陆报名（公网）** | https://jlpt.neea.cn/ |
| 报名咨询电话（教育部考试院相关） | `010-82345676` |

> 两个报名域名内容相同，教育网/公网任选可打开的即可。

---

### 2）选级别（报名之前）

**不必一级一级考。** 按目标与水平直接选：

| 级别 | 大致定位 | 常见用途参考 |
|------|----------|--------------|
| N5 | 入门 | 练手、检验基础 |
| N4 | 基础 | 简单日常 |
| N3 | 日常应对 | 过渡级 |
| N2 | 工作生活常用 | 求职、部分学校 |
| N1 | 较高商务/学术 | 留学、就职加分 |

**建议：**

- 目标留学/就职：多数直接冲 **N2 或 N1**
- 不确定水平：先做 [官方样题](https://www.jlpt.jp/cn/samples/sampleindex.html) 再定级
- 同一次只能报一级；未通过可下次重考同级或改报其他级

**本阶段材料：** 无强制材料；建议备好身份证件信息，并做样题/模考。

---

### 3）注册个人信息

**网址：** https://jlpt.neea.edu.cn/ 或 https://jlpt.neea.cn/

**必要材料 / 信息：**

| 项目 | 要求 |
|------|------|
| 有效身份证件 | 大陆考生：**居民身份证**（号码、姓名等须与证件一致） |
| 外籍等 | 按网站规定：护照等（考试日携带原件规则见下） |
| 电子照片 | 近 6 个月内正面免冠彩色证件照；蓝/红/白底均可；面部清晰、露双耳双眉 |
| 照片格式 | 常见要求：**JPG**，约 **360×480** 及以上，大小约 **20KB～200KB**（以当年报名页为准） |
| 联系方式 | 手机、邮箱（用于接收通知、找回密码） |

**注意：**

- 证件类型、号码、姓名等提交后**通常不可改**，务必一次填对
- 照片会印在准考证上并用于入场核验，**过度美颜/与本人差异过大**可能导致无法入场
- 未成年人也需提前办好有效身份证

---

### 4）报名 + 选考点 + 缴费

**网址：** 同上报名系统

**必要材料：**

- 已注册账号 + 已上传合格照片
- 可用支付方式（按系统提示，一般在线支付）
- 明确想报的 **级别** 与 **考点城市/学校**

**操作要点：**

1. 在报名开放时间内登录 → 选择级别与考点 → 确认
2. 选定后一般需在 **24 小时内缴费**（以系统提示为准）；未缴费前通常可改或取消
3. 缴费成功后，换考点等变更往往有次数限制（常见仅 1 次），以当年《考生须知》为准
4. **考点名额有限，尽早报**

**注意：**

- 报名窗口短，错过只能等下一次（约半年后）
- 报名前仔细阅读网站内的《报名步骤》《考生须知》《常见问题》
- 各考点开放级别可能不同，以系统可选为准

---

### 5）打印准考证

**网址：** https://jlpt.neea.edu.cn/ 或 https://jlpt.neea.cn/（登录后打印）

**必要材料：**

| 项目 | 说明 |
|------|------|
| 报名账号 | 忘记密码可用网站「忘记密码」重置 |
| A4 纸 | **自行打印纸质准考证**（一般不接受仅电子版入场，以考点要求为准） |
| 打印机 | 确保照片、条码/二维码、姓名证件号清晰完整 |

**注意：**

- 打印开放时间以当次通知为准（常在考前约一周）
- 核对：姓名、证件号、级别、考点地址、入场时间是否正确
- 建议多打一份备份

---

### 6）考试当天

**必要材料（缺一不可，常见拒入场且不退费）：**

| 材料 | 说明 |
|------|------|
| **纸质准考证** | 信息完整、照片清晰 |
| **有效身份证件原件** | 须与报名信息**完全一致** |
| 书写工具 | **2B/HB 铅笔**、橡皮（答题卡涂卡） |

**证件类型（常见规定）：**

- 中国大陆考生：有效期内 **居民身份证**原件（唯一常用证件）
- 港澳/台湾/外籍：按准考证与考点通知（如护照、居住证等），以官网/考点通知为准

**考试时段（常见安排，以准考证为准）：**

| 级别 | 大致时段 | 常见截止入场 |
|------|----------|--------------|
| N1、N2 | 上午 | 约 8:55 |
| N3、N4、N5 | 下午 | 约 14:40 |

**考场注意：**

- 提前到校，关注考点入校门禁/停车规定
- 考试期间及休息时间通常**禁止使用手机等电子设备**；入场前关机按要求存放
- 考试结束前一般不得提前离场
- 严禁作弊；严重违规可能导致成绩作废、禁考甚至报警
- 未带准考证/证件、证件过期、信息不符、人证照不符 → **可能拒考且不退费**

---

### 7）查成绩

**网址：**

| 入口 | 网址 |
|------|------|
| 教育网查分 | https://jlpt.neea.edu.cn/qryscore.jsp |
| 公网查分 | https://jlpt.neea.cn/qryscore.jsp |

**需要信息：**

- 本次考试 **准考证号**
- 报名时的 **身份证件号码**

**说明：**

- 开通时间以教育部考试院 / 报名网通知为准（考后约 1.5～2 个月）
- 网上成绩一般仅供参考，**最终以证书和成绩单为准**

**合格规则（官方标准）：**

1. **总分**达到该级合格分  
2. **各单项**均达到及格分（有一科不够，总分再高也不合格）

N1～N3 与 N4～N5 的得分科目划分不同，详见：  
https://www.jlpt.jp/cn/faq/index.html

---

### 8）领取证书 / 成绩单

**方式：** 一般由 **考点** 发放（邮寄或现场领取，以考点通知为准）

**需要：**

- 按考点要求：身份证、准考证号，有的需委托书等
- 关注考点官网/短信/邮件通知

**注意：**

- 材料约考后 **3 个月**到达考点  
- 考点保管期限常见约 **2 年**，逾期可能无法领取，请及时领取  
- 遗失补发规则以官方/考点当期规定为准

---

## 三、注意事项汇总（速查）

1. **不用逐级考**，但 **同一次只能报一级**  
2. **报名窗口短、名额有限**，提前准备照片与证件，开放后尽快缴费  
3. 报名信息与考试日证件必须一致；身份证过期、未办证会直接无法考  
4. 照片要像本人，用于准考证与入场核验  
5. 考试日必带：**纸质准考证 + 有效证件原件 + 铅笔橡皮**  
6. 合格看 **总分 + 各科最低分**，偏科容易挂  
7. 证书本身通常长期有效；用途方若要求「近期成绩」需另看对方规定  
8. 一切以 **当次报名网站通知 + 准考证 + 考点公告** 为准（时间、费用、证件细则可能微调）
