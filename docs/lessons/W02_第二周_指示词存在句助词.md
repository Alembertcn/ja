## 一、G0-02 指示词 こそあど

W01 学了「これ／それ」和「この／その／あの」，本周把整张表补齐。

### 1.1 四组指示词总表

| | こ（近说话人） | そ（近听话人） | あ（离两人都远） | ど（疑问） |
|--|------|------|------|------|
| **事物** | これ | それ | あれ | どれ |
| **修饰名词** | この＋名 | その＋名 | あの＋名 | どの＋名 |
| **场所** | ここ | そこ | あそこ | どこ |
| **方向·礼貌** | こちら | そちら | あちら | どちら |

**记忆法：** 横着看是「远近」，竖着看是「用途」。先定远近（こ／そ／あ／ど），再定用途（れ／の／こ／ちら）。

### 1.2 使用要点

- **これ／この 不能混：** 「これ」单独当名词用（これは本です）；「この」后面必须跟名词（この本は…）。说「これ本」「この は」都是错的。
- **场所词修饰名词要加「の」：** そこのベンチ（那儿的长椅）、ここの食堂（这里的食堂）。
- **こちら 是 ここ 的礼貌版：** 对客人说「こちらへどうぞ」（请往这边走）。「どちら」也可以礼貌地问「哪里／哪位」：お国はどちらですか（您是哪国人）。
- **文章里的 そ：** 写文章指代前面刚提过的东西、地方，用 そ 系。短文②「毎朝そこでコーヒーを買います」的「そこ」＝前一句的便利店。

### 1.3 视角练习（Day1 口练）

| 场景 | 说法 |
|------|------|
| 书在自己手里 | これは本です。／この本はわたしのです。 |
| 书在对方手里 | それは何ですか。／その本は日本語の本ですか。 |
| 书在远处桌上 | あれはだれの本ですか。 |
| 问哪一本 | どれですか。／どの本ですか。 |
| 问洗手间在哪 | トイレはどこですか。 |
| 带客人进门 | こちらへどうぞ。 |

## 二、G0-04 存在句 あります／います

### 2.1 あります 还是 います

| 用 あります | 用 います |
|------|------|
| 物品：本、ペン、机 | 人：田中さん、学生、先生 |
| 建筑：駅、銀行、公園 | 动物：猫、犬、魚 |
| 植物：木、花 | |
| 抽象：時間、会議、休み | |

**判断标准：** 会不会自己动。人和动物用 います，其余都用 あります。植物虽然是活的也用 あります。

### 2.2 两种语序，意思侧重不同

| 句型 | 回答什么 | 例 |
|------|----------|-----|
| 〔场所〕に〔东西〕が あります | 那儿**有什么** | 会社の前に コンビニが あります。 |
| 〔东西〕は〔场所〕に あります | 它**在哪儿** | コンビニは 会社の前に あります。 |

- 第一种：东西是新信息，用「が」。
- 第二种：东西是已知话题，用「は」。回答「～はどこですか」时就用这种。
- 口语里第二种常缩成「コンビニは 会社の前です」，用「です」代替「にあります」。

### 2.3 否定与疑问

| | あります | います |
|------|------|------|
| 肯定 | あります | います |
| 否定 | ありません | いません |
| 疑问 | ありますか | いますか |

> **高频错误：** 存在句否定是「ありません」，不是名词句的「ではありません」。  
> 「食堂は **ありません**」＝没有食堂；「食堂 **ではありません**」＝不是食堂。

否定句里「が」常换成「は」：会社の中に 食堂は ありません。「は」带对比意味：别的或许有，食堂没有。

### 2.4 方位词

| 日语 | 读音 | 中文 |
|------|------|------|
| 上 | うえ | 上面 |
| 下 | した | 下面 |
| 中 | なか | 里面 |
| 外 | そと | 外面 |
| 前 | まえ | 前面 |
| 後ろ | うしろ | 后面 |
| 隣 | となり | 旁边、隔壁 |
| 近く | ちかく | 附近 |
| 右 | みぎ | 右边 |
| 左 | ひだり | 左边 |
| 間 | あいだ | 之间 |

**接法：** 〔名词〕の＋方位词＋に：机の上に、駅の近くに、銀行と郵便局の間に。

> 「隣」多用于同类并排的东西（店和店、人和人）；「横（よこ）」只表示侧面，不讲究同类。本周先记「隣」。

## 三、G0-03 基本助词

助词决定句子里每个名词的「角色」，是 N5～N2 所有语法的地基。本周把最常用的一批一次性理清。

### 3.1 助词总表

| 助词 | 读音 | 作用 | 例 |
|------|------|------|-----|
| は | wa | 话题：说到～ | わたし**は** 学生です。 |
| が | ga | 新信息主语；喜欢／能力的对象 | 猫**が** います。／町**が** 好きです。 |
| を | o | 动作的直接对象 | コーヒー**を** 買います。 |
| に | ni | 存在的地点；具体时刻 | 駅**に** あります。／十二時**に** |
| で | de | 动作发生的场所 | 食堂**で** 食べます。 |
| へ | e | 移动的方向 | 大阪**へ** 行きます。 |
| と | to | 和～一起；A 和 B（全部列举） | 友達**と** 行きます。／土曜日**と** 日曜日 |
| や | ya | A、B 等（举例列举） | 本**や** 雑誌 |
| も | mo | 也 | 銀行**も** あります。 |
| から | kara | 起点（地点、时间） | 駅**から**／九時**から** |
| まで | made | 终点（地点、时间） | 会社**まで**／五時**まで** |
| の | no | 所属、方位（W01 已学） | 会社**の** 前 |

### 3.2 最容易错的三组对比

**① に vs で —— 本周头号难点**

| | に | で |
|--|----|----|
| 搭配 | あります・います（存在） | 食べます・買います・読みます（动作） |
| 问法 | どこ**に** ありますか | どこ**で** 食べますか |
| 例 | 公園**に** 猫が います。 | 公園**で** 本を 読みます。 |

判断：句尾动词是「在那儿存在」就用に，是「在那儿干什么」就用で。

**② と vs や**

| | と | や |
|--|----|----|
| 意思 | A 和 B，就这些 | A、B 等，还有别的 |
| 例 | 土曜日**と** 日曜日は 休みです。 | 本**や** 雑誌が あります。 |

**③ も 的位置**

「も」直接**替换**「は／が／を」：
- 李さん**は** 学生です → 王さん**も** 学生です
- 銀行**が** あります → 郵便局**も** あります
- コーヒー**を** 買います → パン**も** 買います

但「に・で・へ」后面的「も」是**叠加**：公園**にも**、食堂**でも**。

### 3.3 时间词加不加「に」

| 加「に」 | 不加「に」 |
|------|------|
| 具体时刻：十二時に、九時に | 今日、明日、今 |
| 星期：金曜日に | 毎朝、毎日 |
| 有明确范围的时段：昼休みに | いつも、ときどき |

### 3.4 助词叠用

「に」「で」「へ」可以再加「は」或「も」：
- 本屋**には** 雑誌が あります。（说到书店里嘛……）
- 会社の後ろ**にも** 公園が あります。（后面也有……）

叠用时「は／も」总在最后，不能说「はに」「もで」。

### 3.5 基本语序模板

```text
〔谁〕は ＋〔时间〕(に) ＋〔地点〕で ＋〔东西〕を ＋ 动词ます。
わたしは   毎朝          そこで       コーヒーを   買います。
```

日语动词永远在句尾，中间成分的顺序比较自由，靠助词区分角色。先把这个模板练熟，再慢慢调顺序。

## 四、G0-01 です／ます 与普通体入门

| 礼貌体（本阶段主用） | 普通体（先认识） | 用法 |
|------|------|------|
| 学生です | 学生だ | 名词句 |
| あります | ある | 存在（物） |
| います | いる | 存在（人·动物） |
| ですから | だから | 所以 |

- 对同事、老师、陌生人一律用礼貌体；普通体用于朋友、家人和书面文章（である体），W08 前后再系统学。
- **「です」代替动词：** 会議室は三階です（＝三階にあります）、今日は大阪です（＝今天在大阪）。日语常靠「は～です」省掉动词，意思看语境。
- **句尾 ね 与 よ：**「ね」求对方认同（十二時ですね＝十二点对吧）；「よ」告诉对方不知道的事（銀行もありますよ＝那儿还有银行哦）。

### 短文①　在哪儿（对话 · 职场）

**全文（可复制到 TTS）：**

```
李　：田中さん、すみません。ちょっといいですか。
田中：はい、何ですか。
李　：トイレはどこですか。
田中：あそこです。エレベーターの隣にあります。
李　：会議室もこの階にありますか。
田中：いいえ、会議室は三階です。
李　：コピー機はどこにありますか。
田中：会議室の前にあります。
李　：あのう、部長は今どこにいますか。
田中：部長は会議室にいます。
李　：鈴木さんもいますか。
田中：いいえ、鈴木さんはいません。今日は大阪です。
李　：そうですか。この近くに郵便局はありますか。
田中：ええ、駅の前にあります。銀行もありますよ。
李　：田中さん、昼ごはんはいつもどこで食べますか。
田中：会社の近くの食堂で食べます。
李　：何を食べますか。
田中：ラーメンやカレーを食べます。李さんもいっしょにどうですか。
李　：ぜひ。ありがとうございます。
田中：じゃあ、十二時に一階のロビーで。
李　：はい、十二時にロビーですね。
```

> 这篇集中练三件事：**「どこ」问地点**、**あります／います 的区分**、**に（存在）和 で（动作）的对比**。

---

#### ① 李

**日语：** 田中さん、すみません。ちょっといいですか。

**读音：** たなか さん、すみません。ちょっと いい です か  
**罗马音：** Tanaka-san, sumimasen. chotto ii desu ka

**翻译：** 田中，不好意思，现在方便吗？

**解析：**  
想占用对方一点时间时的开场白，字面是「稍微可以吗」。先说「すみません」再接这句，比直接发问礼貌。「いい」是形容词（W03），本周整句记住。

---

#### ② 田中

**日语：** はい、何ですか。

**读音：** はい、なん です か  
**罗马音：** hai, nan desu ka

**翻译：** 嗯，什么事？

**解析：**  
被叫住时的自然回应，语气不冲，只是请对方说下去。「何」后接「です」读 **なん**。

---

#### ③ 李

**日语：** トイレはどこですか。

**读音：** といれ は どこ です か  
**罗马音：** toire wa doko desu ka

**翻译：** 洗手间在哪儿？

**解析：**  
问地点的最简句型 `〔东西／地方〕は どこですか`。「どこ」是「ここ／そこ／あそこ」的疑问词，问路、找东西都用它。

---

#### ④ 田中

**日语：** あそこです。エレベーターの隣にあります。

**读音：** あそこ です。えれべーたー の となり に あります  
**罗马音：** asoko desu. erebētā no tonari ni arimasu

**翻译：** 在那边，电梯旁边。

**解析：**  
- 「あそこ」：离两人都远的地方  
- `〔名词〕の隣に あります`：物品在某处用「あります」，地点后加「に」  

---

#### ⑤ 李

**日语：** 会議室もこの階にありますか。

#### ① わたしの会社は駅の近くにあります。

**读音：** わたし の かいしゃ は えき の ちかく に あります  
**翻译：** 我的公司在车站附近。  
**解析：** `〔东西〕は〔场所〕に あります`，介绍已知事物的位置。

#### ② 駅から会社まで五分です。

**读音：** えき から かいしゃ まで ごふん です  
**翻译：** 从车站到公司要五分钟。  
**解析：** `AからBまで`＝从 A 到 B，地点、时间都能用。分钟读音会变：いっぷん、さんぷん、ごふん、じゅっぷん。

#### ③ 会社の前にコンビニがあります。

**读音：** かいしゃ の まえ に こんびに が あります  
**翻译：** 公司前面有一家便利店。  
**解析：** `〔场所〕に〔东西〕が あります`，便利店是新信息，用「が」。和①对比：①说「公司在哪」，这句说「那儿有什么」。

#### ④ わたしは毎朝そこでコーヒーを買います。

**读音：** わたし は まいあさ そこ で こーひー を かいます  
**翻译：** 我每天早上在那儿买咖啡。  
**解析：**  
- 「そこ」指前句的便利店（文章里指代前文用 そ 系）  
- 语序模板：谁は＋时间＋地点で＋东西を＋动词  
- 「毎朝」不加「に」

#### ⑤ コンビニの隣は本屋です。

**读音：** こんびに の となり は ほんや です  
**翻译：** 便利店旁边是书店。  
**解析：** 以位置为话题说「那儿是什么」，用名词句即可。「～屋（や）」＝某类店：パン屋、花屋。

#### ⑥ 本屋には日本語の本や雑誌がたくさんあります。

**读音：** ほんや に は にほんご の ほん や ざっし が たくさん あります  
**翻译：** 书店里有很多日语书、杂志什么的。  
**解析：** 「には」把地点提为话题；「本や雑誌」举例列举；「たくさん」＝很多，放在动词前。

#### ⑦ 会社の中に食堂はありません。

**读音：** かいしゃ の なか に しょくどう は ありません  
**翻译：** 公司里面没有食堂。  
**解析：** 否定句常把「が」换成「は」，带对比意味。注意是「ありません」不是「ではありません」。

#### ⑧ ですから、昼ごはんはいつも近くの店で食べます。

**读音：** です から、ひるごはん は いつも ちかく の みせ で たべます  
**翻译：** 所以午饭我总是在附近的店里吃。  
**解析：** 「ですから」＝所以，放句首承接原因；普通体是「だから」。「店で食べます」动作场所用で。

#### ⑨ ときどき田中さんもいっしょです。

**读音：** ときどき たなか さん も いっしょ です  
**翻译：** 有时候田中也一起。  
**解析：** 「いっしょです」省略了「いっしょに食べます」。和短文①结尾的约饭呼应。

#### ⑩ 会社の後ろには公園もあります。

**读音：** かいしゃ の うしろ に は こうえん も あります  
**翻译：** 公司后面还有一个公园。  
**解析：** 除了便利店、书店，「公园也有」，所以用「も」。

#### ⑪ 公園にはいつも猫がいます。

**读音：** こうえん に は いつも ねこ が います  
**翻译：** 公园里总有猫。  
**解析：** 动物用「います」。植物、树用「あります」。

#### ⑫ 昼休みに、わたしはそこのベンチで本を読みます。

**读音：** ひるやすみ に、わたし は そこ の べんち で ほん を よみます  
**翻译：** 午休时，我在那儿的长椅上看书。  
**解析：** 「昼休みに」有明确范围的时段可加「に」；「そこのベンチ」场所词修饰名词要加「の」。

#### ⑬ 金曜日の夜は、会社の人と駅前のレストランへ行きます。

**读音：** きんようび の よる は、かいしゃ の ひと と えきまえ の れすとらん へ いきます  
**翻译：** 星期五晚上，我和同事去车站前的餐厅。  
**解析：**  
- 「〔人〕と」＝和某人一起（W01「李と申します」是引用的と，用法不同）  
- 「へ」读 e，表方向，也可换成「に」  

#### ⑭ 土曜日と日曜日は休みです。

**读音：** どようび と にちようび は やすみ です  
**翻译：** 星期六和星期天休息。  
**解析：** 休息日就这两天，全部列举用「と」而非「や」。

#### ⑮ 週末は家で日本語を勉強します。

**读音：** しゅうまつ は いえ で にほんご を べんきょう します  
**翻译：** 周末我在家学日语。  
**解析：** 和④同一个骨架：时间は＋地点で＋东西を＋动词。

#### ⑯ わたしはこの町が好きです。

**读音：** わたし は この まち が すき です  
**翻译：** 我喜欢这个小城。  
**解析：** 喜欢的对象用「が」，不用「を」。「好き」是な形容词，W03 学。

## 九、仿写模板（交付物 3）

把 ○○ 换成自己的真实情况，写 6 句：

```
わたしの家は ○○の近くに あります。
家の前に ○○が あります。
わたしは 毎朝 そこで ○○を 買います。
○○の隣は ○○です。
○○には ○○が います。
週末は ○○で ○○を 勉強します。
```

**自查：** あります／います 用对了吗？「で」和「に」分清了吗？时间词该不该加「に」？
